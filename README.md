### 3. US Baby Names MySQL
Historical US baby names dataset spanning multiple years with naming trends.
- **Data**: Baby names with frequency data across years
- **Focus**: Demographic trends and naming patterns analysis
- [Learn more](./US+Baby+Names+MySQL/README.md)

## Getting Started

Each project folder contains:
- **Data/Dataset**: Raw data files (CSV, etc.)
- **SQL Scripts**: Database creation and data insertion scripts
- **Solution**: Query solutions and analytics examples

### Running the Projects

1. Navigate to the project folder
2. Run the `create_*_db.sql` script to set up the database
3. Run any `insert_*.sql` scripts if present
4. Execute queries from the `solution/` folder

## Requirements

- MySQL or compatible SQL database
- SQL client (MySQL Workbench, DBeaver, etc.)
