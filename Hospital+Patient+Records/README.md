# Hospital + Patient Records

A comprehensive healthcare database project containing patient information, medical encounters, procedures, and organizational data.

## Overview

This project provides a complete healthcare dataset for practicing SQL analytics and generating insights from hospital operations and patient care data.

## Contents

### Data Files
- `patients.csv` - Patient demographic information
- `encounters.csv` - Medical encounters and visits
- `procedures.csv` - Medical procedures performed
- `organizations.csv` - Healthcare organization details
- `payers.csv` - Insurance and payer information
- `data_dictionary.csv` - Column descriptions and data types
- `create_hospital_db.sql` - Database schema creation script

### Questions & Solutions
- `question/hospital_analytics_questions.sql` - Practice SQL questions
- `solution/Hospital_analytics_solution.sql` - Query solutions and answers

## Quick Start

1. Run the database creation script:
   ```sql
   source create_hospital_db.sql;
   ```

2. Import CSV data files into the corresponding tables

3. Practice with questions or explore the solution queries

## Key Tables

- **patients**: Patient demographics and identifiers
- **encounters**: Medical visits and consultation records
- **procedures**: Medical procedures and treatments
- **organizations**: Hospital and healthcare facility information
- **payers**: Insurance companies and payer details

## Use Cases

- Hospital performance analysis
- Patient care pattern analysis
- Procedure analytics
- Payer reimbursement analysis
- Healthcare operational insights
