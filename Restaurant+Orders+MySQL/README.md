# Restaurant + Orders MySQL

A restaurant management database project for analyzing orders, operations, and business metrics.

## Overview

This project provides a relational database structure for managing restaurant operations, tracking orders, and analyzing business performance through SQL queries.

## Contents

### Dataset Files
- `create_restaurant_db.sql` - Database schema and table definitions
- `restaurant_db_data_dictionary.csv` - Data structure documentation

### Solutions
- `Raw_data/solution/solution.sql` - Query solutions and analytics examples

## Quick Start

1. Create the database and tables:
   ```sql
   source create_restaurant_db.sql;
   ```

2. Load your data into the tables

3. Run analytics queries from the solution file

## Database Structure

The database includes tables for:
- Restaurant locations and details
- Orders and order items
- Customers and transactions
- Menu items and pricing

## Use Cases

- Sales and revenue analysis
- Order pattern analysis
- Customer behavior insights
- Menu performance analytics
- Operational metrics and KPIs
